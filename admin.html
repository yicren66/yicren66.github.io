🔑 GitHub 授权 Token：
💡 首次使用：如何花 30 秒获取您的专属 GitHub Token？（仅您本人可修改网站）
  1. 点击打开 GitHub 官方设置页：Fine-grained personal access tokens → 点击右上角 Generate new token。
  2. Token name 随便填（如 homepage-admin），Expiration 选择有效期（如 90 days 或 Custom）。
  3. Repository access 选择 Only select repositories → 勾选 yicren66/yicren66.github.io。
  4. 展开下方 Permissions → Repository permissions → 找到 Contents，将权限改为 Read and write。
  5. 滑到底部点击 Generate token，复制生成的 github_pat_... 粘贴到上方输入框并点击“记住 Token”。（Token 仅保存在您当前浏览器的本地存储中，不会上传到代码仓库，外人访问此页面无法修改您的主页！）
